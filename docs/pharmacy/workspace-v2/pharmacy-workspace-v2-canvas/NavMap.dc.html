Six rules this redesign follows

Places, not featuresSix places match where the work physically happens: the window, the shelf, the store.
Every row says what happens nextIn words, with one action. Other actions sit under the more menu.
One inbox for decisionsNeeds you collects what only someone with your permissions can close.
Limits are honest and smallWhat MedSync does not check is always visible, in one line, never a wall.
Find anythingCtrl K finds patients, prescriptions, batches, slip codes and pages.
Colour means somethingTeal for action, plum for place, amber with an icon and a word for caution, red only for emergencies.

For the build

Gaps in the current code that this design assumes are closed:

  • loading.tsx, error.tsx and not-found.tsx for every place
  • Nav items and feature flags match for Clinical content and Signed packs
  • One dialog wrapper instead of three
  • Network routing gets a page, or leaves the nav
