# MedSync — Resus · ALS arrest console: Clinical Catalog

### Cardiac arrest (adult ALS), reversible causes, special circumstances, ROSC, termination and confirmation of death

> **Status:** CSO-signed at GATE A (2026-09-23, owner instruction "go through all gates"; see
> `docs/resus-v2-gate-a-proposal.md` §12). Source: `docs/resus-v2/resus-desk-v2-clinical-reference.md`
> Sections 2–6, 8, 9, re-verified against the primary pages on **2026-09-23** (§ Verification).
>
> **Posture:** decision support only. The console records what the team does and shows what is due next;
> it never orders, administers, blocks or decides. The leader leads.
>
> **Scope:** adults ≥ 16 y. A child (< 16) gets clocks and logging only — no dose, no energy (PLS not built).
>
> **How the code uses this file.** Every row has a rule ID. The pure engine (`lib/resus/als/**`) and the
> reference file (`lib/resus/reference/als-catalog.ts`) carry the same IDs; every ID has at least one test
> whose name starts with it. A row marked **NOT ENCODED** must never reach the screen as a number.
