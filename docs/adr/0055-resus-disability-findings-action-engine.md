# ADR 0055 — Disability step: a findings→neuro-syndrome→action engine reusing the A/B/C pattern

**Status:** Accepted — CLINICAL-SAFETY artifact (CSO signed the GATE-A model 2026-06-03; "continue and go through all gates")
**Context:** The Disability (D) step is the fourth concrete ABCDE step, built by **reusing the Airway/Breathing/Circulation findings→action→state pattern + visual system** (ADRs 0048–0050, 0053) with neurological-emergency medicine. D is assessed only once A + B + C are secure — and **most reduced consciousness is _secondary_ to A/B/C** (hypoxia, hypercapnia, hypoperfusion, hypoglycaemia), so the engine prompts re-confirming A/B/C before attributing to a primary brain problem. Its content is full of counter-intuitive, lethal traps. Decision-support only; drugs route through the verified smart prescribing tool (ADRs 0051–0052, 0054).

## Decision

1. **Reuse, don't rebuild — on the existing immutable timeline, no new migration.** Findings are `assessment` events (step `D`); actions + state changes are `action`/`drug`/`procedure` events; the current finding-set, neuro-state, suspected syndrome, GCS total + serial trend, and action list are **pure projections** over the timeline. The action-state lifecycle, severity colour + action-state tokens, step bar, and urgency ordering are all reused.
2. **The clinical content is reference data** (`lib/resus/reference/disability-catalog.ts`), transcribed from the CSO catalog (`docs/clinical/resus-disability-clinical-catalog.md`): the five-level neuro-state, the pupils / focal-seizure-posture / glucose-&-raised-ICP findings, the neuro-syndrome vocabulary + per-syndrome strategy, and the Tier 1/2/3 action catalog.
3. **The engine is pure + TDD** (`lib/resus/disability.ts`, 43 tests). **Two outputs:** `classifyDisability` (WORST finding wins → alert → mild_moderate → severe_coma (GCS≤8) → active_seizure_status → raised_icp_herniation; a normal GCS NEVER downgrades a recorded seizure / raised-ICP / fixed-pupil sign) and **`identifyNeuroSyndrome`** (the cause that drives the reversible-first strategy — hypoglycaemia / opioid / status / eclampsia / raised-ICP / stroke / meningitis / DKA-HHS / non-convulsive / secondary-to-ABC / undifferentiated; glucose is ALWAYS considered first). The **D-distinctive element is GCS** — a total computed from its components (verbal scored "T"=1 when intubated) with the **serial trend** (`gcsTrend`/`isGcsFalling` — a falling GCS is a return-to-A trigger). `triggeredActions` is syndrome-driven and enforces the traps; `isDisabilityArrest` (no pulse → the arrest seam); `buildDisabilityActions`, `escalationFor`, `disabilityProceedGuard` (GCS≤8 routes BACK TO A, not E).
4. **The traps are enforced, not just documented:** **"Don't Ever Forget Glucose"** — a reduced-consciousness patient with no glucose recorded is flagged (`mandatoryGlucoseMissing`) and **`d_check_glucose` is pinned at the very top** (priority −1) of the action order; **reduced-GCS-is-ABC** (`abcAbnormal` → `secondary_to_abc` → re-confirm A-B-C); **GCS≤8 → back-to-A → definitive airway**; **Cushing's = raised ICP** (do NOT treat the hypertension as primary); **benzodiazepine at the FULL guideline dose** (lorazepam 4 mg / midazolam 10 mg — never underdose, the dominant SE error); **eclampsia → magnesium FIRST, not a benzodiazepine** (a seizure + pregnancy/postpartum routes to magnesium, never the benzo path); falling-GCS → return-to-A; non-convulsive status → escalate/EEG; pinpoint + reduced consciousness → opioid → naloxone (back to B).
5. **Drugs route through the prescribing tool.** Drug actions (`d_glucose`, `d_naloxone`, `d_benzodiazepine`, `d_eclampsia_magnesium`, `d_flumazenil`) are keys in `RECOMMENDATION_DRUG_MAP` → the pre-filled, dose-verified prescribe dialog; doses are NOT duplicated in the D catalog. Six of D's drugs were already verified in the prescribing catalog (glucose, glucagon, naloxone, lorazepam, midazolam, flumazenil); the **eclampsia magnesium** regimen was the one gap — a NEW `magnesium_eclampsia_iv` entry (4 g IV loading over 5–15 min + 1 g/h maintenance for 24 h; recurrent seizure → 2–4 g over 5 min) was **web-verified 2026-06-03** (Collaborative Eclampsia Trial / Magpie; RCOG/NICE) and carries a look-alike guard distinguishing it from the 2 g arrest / 1.2–2 g asthma magnesium doses + a 4–6 g `doseRangeMg` plausibility bound.
6. **Scope** confirmed at GATE A: record + decision-support + escalation now.

## Scope / deferred

Record + decision-support + escalation now. **Deferred** (record-capable + escalation only, flagged): the full status-epilepticus second/third-line algorithm, detailed stroke-pathway/thrombolysis workflow, ICP-monitoring/osmotherapy protocols, RSI procedural tooling; paediatric (paediatric-GCS + weight-based glucose/benzo/naloxone + febrile-seizure) + obstetric depth. Second-line anticonvulsants / osmotherapy / thiamine are surfaced as record-capable actions + escalation prompts.

## Consequences

**Positive:** a clinically-correct, transparent disability engine where finding → neuro-syndrome → action is explicit; the counter-intuitive lethal traps (glucose-always, reduced-GCS-is-ABC, GCS≤8→A, Cushing's, benzo-full-dose, eclampsia-magnesium-first) are enforced by construction; GCS is computed + trended (the serial fall is a return-to-A trigger); drugs go through the verified prescribing tool; no schema change; A/B/C/D now share one engine + visual system (E follows). **Negative:** `identifyNeuroSyndrome` picks a single most-reversible/most-catastrophic syndrome for a mixed picture (decision-support — the clinician confirms; glucose is always surfaced regardless); the deep SE/stroke/ICP/RSI procedural depth + paediatric/obstetric branches are deferred to record+escalation. The eclampsia magnesium endpoints are web-verified; the `doseRangeMg` band width is CSO-ratifiable.
