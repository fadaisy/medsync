# ADR 0182 — The REF-DX-TERMS v1.1 addendum is seeded uncoded; proposed tests stay unorderable

**Status:** Accepted — 2026-09-28. GATE A (summary and impression) signed by the CSO (D-SI-15, D-SI-26, D-SI-27).
Migration 0085 is GATED and applied by the owner.

## Context

The reasoning catalogue names 187 diagnoses not yet in REF-DX-TERMS and 62 tests not on the default menu. The WHO
ICD-11 browser was unreachable from the build environment, so no proposed code could be verified.

## Decision

1. **Seed the 187 terms uncoded (D-SI-26).** Migration 0085, generated by `scripts/emr/gen-seed.ts` from
   `diagnosis-terms.v1.1-addendum.json`, keys each term `uuidV5("diagnosis_terms:" + id)` with `icd11_code` and
   `verified_on` null and `ON CONFLICT DO NOTHING`; the 15 restricted terms stay restricted. They read "As typed ·
   not coded" and are never HMIS-counted until a later migration adds codes read on the WHO browser. Never ship an
   unverified code.
2. **Until 0085 is applied**, a suggestion of an addendum term is added as typed words; the board still recognises it
   as its profile by name.
3. **Tests (D-SI-27).** The 62 proposed tests show "Not on this hospital's test menu" and cannot be ordered until the
   test addendum is received, signed and merged. Tests on the menu can be added to the plan from Details, with the
   diagnosis as the order's reason.

## Consequences

- ICD-11 verification is owner work: allow `icd.who.int` and `id.who.int` in the environment's network access, read
  each code, and add them by migration.
- `dx.ectopic_pregnancy` is `standard` in the addendum, outside the rule that restricts pregnancy terms under 18
  (D-CFC-09); seeded as the data says, flagged for the CSO.
