# ADR 0050 — Breathing step: a findings→action→state engine reusing the airway pattern

**Status:** Accepted — CLINICAL-SAFETY artifact (CSO authorised the GATE-A model + doses, 2026-06-02; "go through all gates")
**Context:** The Breathing (B) step is the second concrete ABCDE step inside the resus surface (ADRs 0044–0047), built by **reusing the Airway findings→action→state pattern + visual system** (ADRs 0048–0049) populated with respiratory medicine. B is assessed only once A is secure (return to A on any deterioration). It must be deterministic, transparent (show _why_), guideline-anchored (ERC/RCUK 2025; BTS/SIGN 158 2019 + GINA 2025 for acute asthma; NICE CG187 for pulmonary oedema; BTS/ICS 2016 for NIV; ATLS/ETC for tension pneumothorax; Surviving Sepsis 2021), and decision-support only — it records what the team does; it never performs or auto-administers. Procedures (decompression, chest drain, NIV, RSI) are by a skilled operator.

## Decision

1. **Reuse, don't rebuild — on the existing immutable timeline, no new migration.** Findings are `assessment` events (step `B`) carrying a breathing finding-set payload; actions + every state change are `action`/`drug`/`procedure` events carrying `{actionId, actionCode, tier, state}`; reassessment/corrections append new events. The current finding-set, breathing-state, and action list are **pure projections** over the timeline — the exact `classifyAirway` / `buildAirwayActions` shape. The action-state lifecycle, the state colour system + action-state tokens, the step bar, and the urgency ordering are all reused.
2. **The clinical content is reference data** (`lib/resus/reference/breathing-catalog.ts`), transcribed from the CSO catalog (`docs/clinical/resus-breathing-clinical-catalog.md`): the five-level breathing-state, LOOK/LISTEN/FEEL & PERCUSS findings, the **MEASURE banded codes** (RR/SpO₂/PaCO₂/PEF/EtCO₂ thresholds — raw numbers stay in the continuous-monitoring band; the banded codes carry the clinically load-bearing cut-offs + the pre-arrest traps), and the Tier 1/2/3 action catalog, each action citing its source and referencing a dose by id (no dose duplicated as a string).
3. **The engine is pure + TDD** (`lib/resus/breathing.ts`, 48 tests): `classifyBreathing` (WORST finding wins — an optimistic headline read never masks a danger finding → `adequate | distress_compensating | failure_decompensating | peri_arrest | apnoeic`); `triggeredActions` (single findings + the life-threat clusters — tension pneumothorax, massive haemothorax, open chest wound, acute/life-threatening asthma, COPD, pulmonary oedema, pneumonia/sepsis, PE, anaphylaxis — each with its rationale, least-invasive-first / emergencies-prominent ordering); `isBreathingArrest` (apnoea + **no signs of life / pulseless** → the arrest seam; apnoea **with a pulse** → ventilate (bag-mask), NOT CPR — the same pulse-dependent split the airway review established); `buildBreathingActions` (folds state changes by `actionId`); `escalationFor` (`failed`→next step); `breathingProceedGuard` (treat-before-proceeding to C; an unassessed breathing is not "safe"; distress "compensating" still flags — it will fail).
4. **The pre-arrest traps are first-class critical findings** (proposal §A.7): **silent chest**, **falling RR / exhaustion / drowsiness**, **normalising/rising PaCO₂ in acute asthma**, **rising EtCO₂ with falling RR** each classify as `peri_arrest` and surface at the top with an explicit "do NOT mistake a quiet chest or a 'normal' CO₂ for improvement" rationale. **Normal SpO₂ + high work** classifies as distress-that-will-fail, never falsely reassured. Cyanosis is labelled a late sign.
5. **Action-state vocabulary** (reused unchanged): `indicated / in_progress / performed / not_indicated / deferred / failed`; **`failed` drives the next step** — the UI surfaces the `escalatesTo` action inline.
6. **Doses (web-verified 2026-06-02; zero `needs-CSO-verification`):** four NEW FIXED cited constants for acute asthma — salbutamol **5 mg** neb, ipratropium **500 µg** neb, **prednisolone 40–50 mg PO or hydrocortisone 100 mg IV**, **IV magnesium 1.2–2 g over 20 min** (BTS/SIGN 158 2019 + GINA 2025). Reused fixed constants: IM adrenaline (anaphylaxis — surfaced **FIRST, before salbutamol**), O₂, sepsis crystalloid/MAP. **Category-level** (no fixed surface dose): PE thrombolysis (senior), pulmonary-oedema GTN + furosemide (NICE CG187 fixes none), CPAP/NIV in oedema (conditional). **Threshold (non-drug):** COPD-NIV trigger pH < 7.35 + PaCO₂ > 6.5 kPa. **Citation corrections ratified** (§D): acute asthma = BTS/SIGN 158 2019 + GINA 2025 (not NG245, which excludes acute attacks); pulmonary oedema = NICE CG187 (2014); tension-pneumothorax needle length labelled ATLS.

## Scope / deferred

Record + decision-support + escalation now. **Deferred** (record-capable + escalation only, flagged): full ventilator setup / NIV-titration / RSI drug-checklist / chest-drain _procedural_ tooling; paediatric (age-banded RR/SpO₂; bronchiolitis/croup; weight-based doses; grunting/head-bobbing/recession red flags) + obstetric depth (the engine routes by age).

## Consequences

**Positive:** a clinically-correct, transparent breathing engine where finding→why→action is visible and every act + state is on the immutable medico-legal record; no schema change; it confirms the airway shape is a faithful B–E template (same engine signatures, same colour tokens, same proceed-guard discipline). The pre-arrest traps — the commonest fatal misreads in respiratory emergencies — are encoded as critical and unmissable. **Negative:** the projection is recomputed from the timeline each render (cheap at resus scale); category-level items intentionally show no number; PE is gated on clinician suspicion (non-specific on exam alone) rather than auto-fired; advanced ventilatory depth is deferred. Changing a finding/action/mapping/dose is a CSO-authored, traceable change.
