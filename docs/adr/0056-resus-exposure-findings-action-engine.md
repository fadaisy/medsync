# ADR 0056 — Exposure step: a findings→diagnosis→action engine + the return-to-A loop (completes ABCDE)

**Status:** Accepted — CLINICAL-SAFETY artifact (CSO signed the GATE-A model 2026-06-03; "go through all gates")
**Context:** The Exposure (E) step is the **fifth and final** concrete ABCDE step, built by **reusing the A/B/C/D findings→action→state pattern + visual system** (ADRs 0048–0050, 0053, 0055) with "what got missed" emergency medicine. E is done after A–D, then the survey **returns to A and cycles** — a resuscitation is a continuous loop, not a single pass. Decision-support only; drugs route through the verified smart prescribing tool (ADRs 0051–0052, 0054). **This completes the ABCDE primary-survey set (A/B/C/D/E on one engine).**

## Decision

1. **Reuse, don't rebuild — on the existing immutable timeline, no new migration.** Findings are `assessment` events (step `E`); actions + states are `action`/`drug`/`procedure` events; the current finding-set, exposure-state, suspected-diagnosis, temperature stage, and action list are **pure projections**. The action-state lifecycle, severity + action-state colour, step bar, and urgency ordering are all reused.
2. **The clinical content is reference data** (`lib/resus/reference/exposure-catalog.ts`), transcribed from the CSO catalog (`docs/clinical/resus-exposure-clinical-catalog.md`): the four-level exposure-state, the skin/rash + bleeding-injury + patches findings, the suspected-diagnosis vocabulary + per-diagnosis strategy, the temperature staging, and the Tier 1/2/3 action catalog.
3. **The engine is pure + TDD** (`lib/resus/exposure.ts`, 40 tests). **Two outputs:** `classifyExposure` (WORST finding wins → no_new_critical → significant → temperature_extreme → critical; a temperature extreme is never downgraded by an otherwise-benign survey) and **`identifyExposureDiagnosis`** (anaphylaxis / meningococcal-sepsis / occult-haemorrhage / nec-fasc / limb-threat / severe-hypothermia / hyperthermia / hypothermia / opioid-patch; most-time-critical first). `tempStage` stages the core temperature (boundaries round to the more-severe band — 28.0 → severe, 32.0 → moderate — so the threshold gets the more-aggressive rewarming). `triggeredActions` is a **checklist** (the baseline expose / measure-temp / re-cover / AMPLE / return-to-A is always surfaced) that adds **every CRITICAL findings-based action UNCONDITIONALLY** — the lesson from the D review: a co-morbid critical must never be masked by the single winning diagnosis. `isExposureArrest` (no pulse → the arrest seam, with the hypothermia modifier); `temperatureMissing`, `buildExposureActions`, `escalationFor`, and `exposureCycleGuard` (the return-to-A loop).
4. **The traps are enforced, not just documented:** non-blanching rash → **don't-delay antibiotics**; unexplained hypothermia → **cold-sepsis** septic screen; occult haemorrhage → **log-roll** (fired by trauma OR a recorded back finding) + back-to-C; **expose → examine → RE-COVER + keep warm** (always surfaced; escalated when `notRecovered`); hypothermic arrest → the **"not dead until warm and dead"** modifier on the arrest banner; transdermal opioid patch → **remove + naloxone**; and **after E → RETURN TO A** (the loop).
5. **The E-distinctive element: the RETURN-TO-A loop.** E is not a dead-end. The panel surfaces a prominent "primary survey complete → return to A and reassess" affordance that **auto-records the draft first** (so nothing — especially AMPLE allergies — is lost), records the loop event (`recordResusReturnToA`), and navigates the desk back to A. The cycle guard is **advisory, not a hard block** — a resus is non-linear and an urgent jump-back to A (e.g. airway found compromised) must always be possible; when the guard is unmet the CTA reads "Return to A anyway".
6. **AMPLE history feeds the prescribing-tool allergy check.** AMPLE allergies captured in E are written (by `recordExposureFindings`) as an `allergyCapture` note — the same store the prescribe-time allergy check reads — so an allergen learned at E protects every subsequent prescription.
7. **Drugs route through the prescribing tool — NO new dose.** All of E's drugs already exist web-verified in the catalog: `e_antibiotics` → `sepsis_antibiotics`, `e_anaphylaxis_adrenaline` → `adrenaline_anaphylaxis_im`, `e_warmed_fluids` → `crystalloid_bolus`, `e_naloxone` → `naloxone_iv`. Only new `e_*` recommendation codes were added. Dantrolene (malignant hyperthermia) is deferred to record + escalation.

## Scope / deferred

Record + decision-support + escalation now. **Deferred** (record-capable + escalation only, flagged): the full hypothermia/ECLS pathway, detailed heatstroke-cooling, burns (TBSA/Parkland), nec-fasc/surgical pathways, secondary-survey tooling, toxidrome/poisoning workflow, dantrolene/MH, structured fluid-temperature capture (the "~40 °C warmed fluid" requirement is carried in the action wording, not enforced); paediatric (+NAI awareness) + obstetric depth.

## Consequences

**Positive:** a clinically-correct, transparent exposure engine where finding → diagnosis → action is explicit; the counter-intuitive lethal traps (non-blanching-rash→antibiotics, cold-sepsis, occult-haemorrhage-via-log-roll, expose→re-cover, hypothermic-arrest modifier) are enforced by construction; co-morbid criticals are never masked; the primary survey **cycles** (E returns to A) instead of dead-ending; AMPLE allergies protect later prescriptions; drugs go through the verified tool with no new dose; no schema change. **A/B/C/D/E now share one engine + visual system — the ABCDE primary survey is complete.** **Negative:** the return-to-A guard is advisory (a deliberate choice for a non-linear resus); fluid-temperature isn't structurally captured; the deep hypothermia/heatstroke/burns/nec-fasc/secondary-survey depth + paediatric/obstetric branches are deferred to record+escalation.
