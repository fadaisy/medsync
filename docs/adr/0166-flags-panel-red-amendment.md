# ADR 0166 — Red in the clerking Flags panel (Law 8 amendment)

**Status:** Accepted — 2026-09-27. GATE A D-CV-03, signed by the CSO.

## Decision

In the clerking desk's Flags panel only, a badge for an **urgent** flag may use the status-critical tint.

- It always carries an octagon icon and an accessible name ending "urgent".
- Caution badges use the status-caution tint, a triangle icon and the accessible name "needs attention".

Everywhere else, red keeps its meaning: critical result values, a NEWS2 parameter scoring 3 where the reading is shown, and the Emergency affordance. The red-scarcity tests cover every new component.
