# REF-DX-TERMS v1.1 addendum: ICD-11 codes, sign-off record

The 187 terms of `diagnosis-terms.v1.1-addendum.json` were seeded uncoded by migration 0085 (D-SI-26, ADR 0182).
This record is what the CSO signed on 28 Sep 2026; `data/emr/diagnosis-terms.v1.1-icd11.json` holds it as data and
generates migration 0086 (ADR 0183).

**Method.** A token from `icdaccessmanagement.who.int`; the release in force read from `id.who.int/icd/release/11/mms`
(2026-01). Each term was searched by its display (without ", cause not yet known"), each half of an "or" term and up to
five synonyms. Every candidate was then re-read as a WHO entity (`codeinfo` → entity) for its code, title and class
kind; the search's first answer was rejected wherever it was wrong, too narrow or asserted something the term does not
(about 20 places, each noted). Codes and titles below are WHO's own; nothing was typed from memory or a mirror. Every
alternative code named in a note was resolved the same way.

Read from the WHO ICD-11 API, MMS release **2026-01**, on 2026-09-28. Each code was re-read as a WHO entity
(codeinfo → entity), so every title below is WHO's own. 187 terms: A 138, B 34, C 5, D 10.

Match: **title** = WHO's title is the term or one of its synonyms; **index** = a WHO index entry (synonym, inclusion or
'… NOS') is the term or a synonym; **near** = same concept in WHO's wording, checked by hand; **nearest** = no exact
WHO concept, the nearest one chosen by hand (see note).
Restricted terms are marked 🔒. 'Addendum' is the unverified code the addendum carried (proposal or findacode hint).
