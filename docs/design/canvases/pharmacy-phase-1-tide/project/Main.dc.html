How the lanes work at this hospital. A prescription goes to Pharmacist first when it carries a reason this hospital has switched on: a stop the prescriber overrode, a controlled drug, a child under [age], a kidney function flag, or a medicine on the hospital's high-risk list. Everything else is Standard and is checked by the person who supplies it.
  • Each reason is switched on at GATE A by the Clinical Safety Officer, with the counts in front of them.
  • Stock never moves a prescription between lanes. It only helps you order the work.
If no review rule is signed, there is one lane and this line reads: "This hospital has not signed its review rule, so every prescription needs a pharmacist."
  • Waiting has no colour and no target. This slice signs no waiting time.
  • Payment is shown as recorded. It never disables anything on this page.
