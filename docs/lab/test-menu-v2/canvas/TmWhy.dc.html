Why the test menu is simpler

Set up tests, not results

The Diagnostics page today lists every LOINC code on its own: haemoglobin, MCV and platelets each need a section, a place, hours and a turnaround, and a Full blood count is 27 rows. Version 2 lists what doctors order. Each test comes from the catalogue with its section, specimen, tube and codes already attached.

Now97 rowsOne row per LOINC result, category "Laboratory" for 88 of them. 67 not set. A full blood count alone is 27 rows to classify. C3, C4, ANA and anti-dsDNA are missing.
Version 2291 tests · 8 sectionsOne row per orderable test, each with a recommended section. Start from your level adds 215 tests for a regional referral hospital in one step; the lab changes only what differs. 556 results sit inside those tests and never need a section of their own.
