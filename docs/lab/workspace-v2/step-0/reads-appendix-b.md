## Live channel, caching

- `LabLive` (`components/lab/lab-live.tsx`) subscribes to `lab:<hospitalId>`. Events: collected, received, rejected, receipt_undone, resulted, released, referral_updated, match_waiting, message_dead. It calls `router.refresh()` and exposes no state. It is mounted only on the worklist, and only with `LAB_BENCH`. When the channel is down, it polls every 15 s and shows an **amber** "Live updates paused".
- `user:<id>` carries critical alerts (`components/medsync/critical-live.tsx`).
- The only caching is React `cache()`. There is no `unstable_cache` / `"use cache"` in lib/lab. 0118 has no cache, by design (QI-3).
