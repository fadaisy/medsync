# NCDSync hazard log

Opened with the first build (2026-10-05). Owner: the Clinical Safety Officer, co-reviewed by the Registry Technical Group.
Each hazard names the control built and the test that proves the control. Residual risk is what remains for human review;
none of it is closed by this build.
