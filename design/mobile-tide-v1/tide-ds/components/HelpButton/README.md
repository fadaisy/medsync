# HelpButton

The emergency affordance, the only red fill in the app: a Help pill in the header of every screen, and a full-width "Get help now" inside a dangerous moment.

**Use** the header pill top-right on every screen, signed in or not, so help is always one tap away (MedSync's minimum safety floor). Use "Get help now" only on the dangerous-reading and symptom-interrupt screens. Both open the emergency sheet: call first, then tell a hospital.

**Values** `emergency` fill, `on-emergency` text (4.8:1), `shadow-emergency`. Header pill 40 high (48 hit area); Get help now 56 high, full width.

**Don't** use red for anything else, including notification badges, delete or cancel. Never animate, pulse or flash it. Never hide it behind a menu.
