# ReadingField

Large number boxes for entering a home reading, each labelled, with the unit and a plain hint of where to find the numbers.

**Use** for blood pressure (two boxes), glucose, weight and pulse (one box). Opens the phone's number pad. As soon as both numbers are in, a StatusPill appears beneath, worked out on the phone so it works offline. A dangerous value hands over to the dangerous-reading screen on save.

**Values** boxes `surface`, `radius-lg`, `shadow-card`; focused box gets a 2px `accent` ring and a 5px `accent-tint` halo. Value 44/48 at 600, tabular; label `overline` `ink-2`.

**Don't** use sliders or steppers for readings; hide the unit; colour the box by state (the pill says it).
