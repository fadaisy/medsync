# PersonCard

A member of the patient's care team, with round message and call buttons, as in the reference's contact card.

**Use** on visit detail and in Care team. Message is the `accent` disc (the usual way to reach the team); call is a `navy-900` disc (a real phone call to the clinic line). Both carry an `aria-label`, and on first use a one-line hint says what each does.

**Values** `surface`, `radius-lg`, `shadow-card`; initials avatar 48 on `surface-sunken` in `area-team`; round buttons 46.

**Don't** colour the call button red (red is only Help); show a clinician's personal number; use a stock photo for a real clinician.
